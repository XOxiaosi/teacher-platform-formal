# 教师 AI 工作平台｜正式版工作空间

这是正式版的新工作空间。旧项目只作为历史材料和能力来源，本目录不会直接继承旧前端页面，也不会把旧版的临时实现状态当成正式版要求。

## 当前阶段

当前只做产品范围确认和云端上线前置规划，尚未迁移代码、选择云服务商、购买服务器、申请域名或接入真实学生数据。

当前执行入口是 [下一步任务清单](./NEXT-TASKS.md)：先逐项关闭产品决策包，同时并行做原创页面状态图、外部可行性调研和 RC2 历史固化方案；这些完成前不开始正式功能代码。

## 当前工作边界

- 正式版面向云端运行，教师通过网页和微信使用。
- Windows 11 是开发、浏览器使用和验收环境，不是默认生产服务器。
- 第一版包含微信、真实语音转文字和真实图片文字识别。
- 微信只处理教师主动发起的对话；平台不主动或自动向教师、家长发送微信消息。
- 云端部署地区已确认为中国大陆，资源申请主体已确认为个人。
- 第一期按 150 名个人教师规划，每位教师扫码绑定自己的个人微信，由微信 Bot 与平台交互。
- 原始音频和图片处理成功后需要删除；处理失败时保留原件用于追溯和重试。成功后的准确删除触发点仍待确认。
- 产品能力确认前，不开始正式功能开发。
- 正式版代码只从确认过的能力和业务规则中逐项迁入，不整包复制旧项目。
