# T-016 网页核心教学闭环执行合同

## 结论

T-016 按 V003 已确认范围直接实施，不再等待微信、公众号、小程序、OCR、ASR、AI、缴费或部署。完成标准不是“旧页面能够打开”，而是两名合成教师都能在网页中独立走通：

> 建学生 → 排一对一或小班课程 → 在 Today 查看 → 完成课程 → 核对文字候选 → 保存正式工作记录 → 在学生时间线复查

只有完整 Gate 通过后，T-016 才能从“进行中”改为“已完成”，并计入 9% 项目进度。

## 产品边界

- 只做电脑网页和 375–430px 手机网页。
- 所有课程排期列表、卡片、日历摘要、检查器和无障碍文本只显示：时间、地点、参与人、上课形式、独立操作备注。
- 不显示或变相复制课程名称、科目、授课内容、本节课目标、教学目标、进度、年级、单元或课次。
- 备注只保存小测、提问、订正检查等操作提醒，不承担授课内容字段的职责。
- 一对一必须关联 1 名正式学生；小班必须关联至少 2 名正式学生，不使用自由文本伪造参与人关系。
- 文字原始事件和候选保持独立。教师必须看见逐字原文、选择归属并点击确认，候选才可成为正式工作记录；不得自动确认、自动改写或调用 AI。
- 不接真实账号或真实资料，不使用外部密钥，不产生费用，不部署，不发送消息，不删除 legacy。

## 数据与接口合同

### 学生

- 教师身份只来自当前 Session。
- 学生创建、读取、修改和深链恢复都按 `teacherId + id` 校验。
- 跨教师对象与不存在对象返回相同结果，不泄露对象是否存在。

### 课程与参与人

- `Schedule` 增加地点、上课形式和独立操作备注；敏感文本按现有字段加密边界处理。
- 新增正式课程参与人关系，保存课程、学生和教师归属。
- 旧 `Schedule.title` 与单个 `studentId` 只作兼容读取；新网页不要求、不显示，也不从中推断缺失字段。
- 旧课程缺少结构化字段时明确显示“地点待补充”“参与人待补充”“形式待补充”或“暂无备注”。
- 改期复制正式五字段与参与人关系，不复制或暴露旧标题。

### 完课

- 一对一完课创建 1 条参与人课次；小班为每名参与人各创建 1 条课次。
- 完课、课次创建和审计在同一事务中完成。
- 重复点击、并发请求和网络重试不得重复创建课次；部分失败不得留下“课程已完成但课次不完整”的状态。

### 工作记录

- `CaptureEvent` 继续保存不可被正式记录覆盖的原始事实。
- `CaptureCandidate` 保存待核对状态和最终确认去向。
- 教师选择学生，可选关联已完成课程，再明确确认。
- 正式记录保留原始事件引用；删除、跨教师引用、冲突确认和重复确认都必须安全拒绝或幂等重放。

### Today 与周视图

- Today、Week、课程列表和检查器从正式课程字段读取信息。
- Agenda 输出和受控引用标签不得包含 legacy 标题或其他授课内容。
- 小班人数不改变“课程节数”统计，一场小班仍是一节课程。

## 实施波次

### Wave 1｜数据与教师边界

1. 新增课程五字段、正式参与人关系和幂等/并发约束。
2. 修正学生、课程、课次和候选确认的 owner 查询与跨对象引用。
3. 完成空库迁移和带旧课程数据的升级测试；不修改旧标题内容，不自动补造缺失字段。

### Wave 2｜后端垂直闭环

1. 接通建学生、排一对一、小班、取消、恢复、改期和完课。
2. 接通文字候选的显式确认与正式记录追溯。
3. 接通 Agenda 五字段投影、学生时间线和每日回顾去重统计。

### Wave 3｜电脑与手机网页

1. 排课表单改为时间、地点、参与学生、形式和备注。
2. 课程列表、周视图、电脑 Today、手机 Today 和检查器全部消费正式字段。
3. 记录核对页支持选择归属、显式确认、失败恢复和成功后查看学生档案。

### Wave 4｜集成与独立验收

1. 两名合成教师用真实 Session 分别走完整闭环。
2. 执行跨教师读、写、修改、取消、完课、候选确认和对象引用攻击矩阵。
3. 执行刷新、前进后退、重复点击、网络重试和并发测试。
4. 在电脑和 375/390/430px 手机视口做真实浏览器验收与禁词扫描。
5. 运行根测试、typecheck、lint、build、文件长度、Prisma 迁移和 MIG-002 manifest 校验。
6. 由独立 Reviewer 复核 P0/P1/P2；P0/P1 未归零不得标记完成。

## 完成 Gate

- 一对一人数不为 1、小班少于 2 人时，前后端都拒绝创建。
- 地点和参与人缺失的新课程不得创建；备注允许为空。
- 课程五字段能在刷新后从数据库恢复，界面不依赖临时内存推断。
- 小班完课后每位参与人恰好 1 条课次，并发完课不重复写入。
- 文字候选确认失败不改变候选，不产生部分正式记录；确认成功可在学生时间线复查并追溯原始事件。
- 另一教师无法读取、修改或引用本教师的学生、课程、参与人、课次、原始事件、候选和正式记录。
- API JSON、可见文本、ARIA 文本和截图中均不出现被禁止的课程内容字段或旧标题值。
- Today 与周视图只显示当前教师数据；小班按一节课程统计。
- 根完整 Gate 退出 0，迁移临时数据库和进程无残留，MIG-002 清单与当前目标文件哈希一致。
