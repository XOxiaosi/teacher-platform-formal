# T-010｜V001 关键页面状态合同（待一次确认）

> 状态：候选已就绪，等待用户一次确认
>
> 产品事实源：`PRODUCT.md` V001
>
> 本文件只冻结网页的信息结构、可见状态和验收结果，不新增产品能力，也不授权开发外部服务、使用真实资料、采购、部署或上线。

## 1. 本阶段要得到的结果

正式网页必须让教师在电脑和手机上完成以下任务，并在刷新、失败、空数据和需要确认时仍知道“现在发生了什么、下一步做什么”：

1. 从今日进入当天课程、待确认事项和到期备忘。
2. 查找或新建学生，并进入一个学生的长期档案。
3. 从月历选择日期，查看、新建、改期、取消、恢复和完成课程。
4. 输入一段教学事实，保留原文并核对候选记录。
5. 登记缴费与课时，查看可追溯余额，不直接改余额。
6. 在明确学生或工作上下文中使用 AI，核对并逐次确认高影响操作。

## 2. 全局网页壳

### 电脑网页

- 左侧固定一级导航：今日、学生、日程、记录、缴费课时、AI 助手。
- 隐私、反馈、每日回顾和设置进入次级区域；当前 V001 不显示微信、公众号、小程序或模型密钥配置。
- 主内容区保留一个清楚的页面标题、当前上下文和最多一个主要操作。
- `1440×900` 使用完整侧栏；`1366×768` 可以收窄侧栏，但不能只剩难以理解的首字圆圈。

### 手机网页

- 顶部只保留返回或菜单、页面标题和当前页主要操作；全部导航从覆盖式菜单抽屉进入。
- 不使用横向滚动的全量导航，也不照搬固定五项底栏。
- 菜单、会话和表单抽屉打开后管理焦点，关闭后焦点回到触发按钮；触控目标至少 `44×44px`。
- `375 / 390 / 430px` 不出现页面级横向溢出，底部安全区不遮挡输入与确认按钮。

### 首页与身份状态

- 登录成功默认进入 `/today`，不以 AI 页面作为首页。
- 未登录访问业务地址时进入 `/login?next=原地址`；登录后回到原地址。
- 会话过期时保留尚未提交的文字草稿，重新登录后由教师决定是否恢复。
- 管理员和教师使用独立入口；教师页面不出现管理员冒充入口。

## 3. URL 与恢复规则

| 页面 | 正式地址 | 必须恢复的状态 |
|---|---|---|
| 今日 | `/today?date=YYYY-MM-DD` | 选中业务日期、焦点事项 |
| 学生列表 | `/students?q=关键词` | 搜索条件与列表位置 |
| 学生详情 | `/students/:studentId?tab=overview|timeline|records|communications` | 当前学生与页签 |
| 日程 | `/schedules?month=YYYY-MM&date=YYYY-MM-DD&view=month|week` | 月份、日期与视图 |
| 新建记录 | `/records/new?studentId=:studentId` | 当前学生；未提交正文只保存在本机草稿 |
| 候选核对 | `/records/:recordId/review` | 原始材料、候选版本与核对位置 |
| 缴费课时 | `/ledger?studentId=:studentId` | 当前学生与筛选条件 |
| AI 助手 | `/agent/:conversationId` | 当前会话、学生上下文与待确认操作 |

- 页面切换必须更新浏览器地址；复制地址、刷新、前进和后退得到同一业务上下文。
- 无效参数显示可恢复说明并回到安全默认值，不能静默跳到另一个学生、日期或会话。
- 不存在或不属于当前教师的对象统一显示“无法访问”，不泄露对象是否属于别人。

## 4. 全局状态词典

每个主页面按需要覆盖以下状态，名称和表现保持一致：

| 状态 | 教师看到什么 | 可执行动作 |
|---|---|---|
| 首次加载 | 页面骨架和明确标题 | 等待；不显示假数据 |
| 成功有数据 | 最新可信内容和生成/更新时间 | 进入详情或主要操作 |
| 成功空状态 | 为什么为空、第一步能做什么 | 一个主操作 |
| 后台刷新 | 保留旧内容并显示“正在更新” | 可继续阅读，不重复提交 |
| 刷新失败 | 保留旧内容，标明数据时间和失败 | 重试 |
| 首次加载失败 | 错误摘要，不回显底层路径或供应商机密 | 重试、返回安全页 |
| 离线 | 本机草稿状态和不可用动作 | 继续编辑草稿、恢复连接 |
| 保存中 | 当前对象和进度 | 禁止重复提交 |
| 部分成功 | 已成功项、失败项和未完成项分别列出 | 只重试失败项 |
| 冲突 | 冲突对象、来源和差异 | 返回修改或明确覆盖 |
| 权限/对象不可用 | 固定的安全说明 | 返回列表 |
| 会话过期 | 登录已失效，草稿未提交 | 重新登录 |
| 额度耗尽 | 哪项外部能力暂停、何时恢复 | 继续文字输入与人工编辑 |

## 5. 今日工作台 `/today`

### 默认信息顺序

1. 上海业务日期、当天课程数、待确认数和到期备忘数。
2. 下一节课程或正在进行的课程。
3. 待确认动作，按风险和截止时间排序。
4. 到期备忘与需要补记录的已完成课程。
5. “记录一件事”主操作，以及新建课程次操作。

### 专属状态

- 没有课程、没有待确认和没有备忘分别说明，不把整页合并成模糊空态。
- 日期不是今天时明确显示“正在查看某日”，并提供返回今天。
- 刷新失败保留旧内容和生成时间；不得把旧内容伪装成最新。
- 点击课程、学生、备忘或待确认项进入带焦点的真实地址。

## 6. 学生列表与学生详情

### 学生列表 `/students`

- 默认按最近有教学活动排序，支持姓名和年级搜索；搜索条件进入 URL。
- 有学生时，条目整体进入详情，不在按钮中嵌套另一个链接。
- 空列表显示“建立第一个学生”；搜索无结果保留搜索框并提供清除条件。
- 新建学生采用桌面侧面板、手机全屏表单；提交前检查必填与可能重复，不因重复姓名自动合并。

### 学生详情 `/students/:studentId`

- 顶部只显示姓名、年级、状态、阶段目标和本次主要操作。
- 页签固定为概览、时间线、记录、沟通；缴费课时和 AI 通过带学生上下文的受控入口进入。
- 概览展示下一节课程、课时余额、待确认候选和最近变化，不堆叠所有编辑表单。
- 时间线按原始事实时间排序，清楚区分候选、已确认、已拒绝、已更正和原件已删除。
- 找不到或无权访问学生时显示同一安全状态，不能自动切到别的学生。

## 7. 日程 `/schedules`

### 默认结构

1. 月份切换与返回今天。
2. 月历概览：日期、今天、选中日、最多三枚带文字图例的状态标记。
3. 当月摘要：已完成课时、待确认改期/冲突、待续费学生。
4. 选中日期的纵向课程列表。
5. 新建课程。

- 手机始终以月历＋选中日纵向列表为主；周视图只是次级入口。
- 选择日期、月份和周视图都进入 URL；“今天”来自可信服务端时间。
- 新建、改期、取消、恢复和完成都显示课程、学生、原时间、目标时间和冲突结果。
- 取消后提供有时限的恢复；已经影响课时或记录时，必须说明关联结果，不直接静默回滚。

## 8. 记录输入与候选核对

### 输入 `/records/new`

- 首批首先支持文字；媒体入口只有在后续真实 OCR/ASR Gate 通过后才开放。
- 页面明确显示当前学生；全局进入时不自动猜学生，必须由教师选择。
- 提交后先保存不可覆盖的原始输入，再产生候选；按钮文案使用“保存并生成候选”，禁止“自动归档”。
- 离线时只保存在本机草稿并明确未上传；恢复网络后由教师主动提交。

### 核对 `/records/:recordId/review`

- 同屏展示原始输入、识别/AI 版本、置信提示、候选字段和修改区。
- 每个正式字段显示来源；低可信和冲突不能只靠颜色。
- 教师可以修改、拒绝或确认候选；确认后生成结果回执并保留修订关系。
- 删除原件、删除候选和删除正式记录是三个不同动作，必须分别说明影响。

## 9. 缴费课时 `/ledger`

- 顶部按学生展示购买、已消耗、剩余和待核对课时，所有数字可追溯到流水。
- 登记缴费、补记课时、完课消耗和更正分别形成流水；不提供直接编辑余额。
- 金额、课时、学生、日期和备注提交前可核对；重复交易给出疑似重复提示，不自动吞掉。
- 会造成负课时、修改历史流水或跨学生的操作必须阻断或逐次确认。
- 外部支付不在 V001；“已登记缴费”不得写成“平台已收款”。

## 10. 上下文 AI `/agent/:conversationId`

### 电脑网页

- 左侧会话栏、中央消息与确认区、右侧可收起上下文；`1366×768` 时上下文默认收起，不能挤压消息正文。
- 会话栏收起不卸载会话、不清除草稿、不打断生成。

### 手机网页

- 顶部会话按钮打开覆盖式左抽屉；抽屉关闭后聊天使用完整页面宽度。
- 会话列表、消息正文和上下文不能三栏并排，也不能横向截断确认内容。
- 选择会话后关闭抽屉；系统返回先关闭抽屉，再按浏览器历史返回。

### 专属状态

- 覆盖首次无会话、搜索无结果、加载、生成中、等待确认、部分完成、失败、离线、会话过期和外部能力暂不可用。
- 每个会话独立保存草稿、学生上下文和待确认操作；切换会话不能串内容。
- 确认卡必须用教师语言显示对象、来源、旧值、新值、影响和有效期；技术动作名只进入可展开详情。
- 生成失败时列出已经完成的安全步骤，只重试失败步骤；没有真实模型时显示“暂不可用”，不返回假分析。
- 不显示模型 API Key 设置；家长材料只能复制或导出，不能直接发送。

## 11. 删除、确认与结果回执

- 普通放弃草稿不弹高风险确认；会丢失已上传材料或正式记录时才使用确认面板。
- 高影响确认面板固定展示：操作对象、来源、当前值、执行后值、关联影响、是否可恢复。
- 确认只对当前操作有效；刷新、重复点击和网络重试不能重复执行。
- 成功后显示结果回执和可追溯入口；失败显示未改变的事实与重试范围。
- 危险操作不使用浏览器原生 `confirm`，也不让整张卡片点击即执行。

## 12. 视觉与可访问性 Gate

- 首批 Today、Students、Student detail、Schedules、Record review、Ledger 和上下文 AI 提供 `1440×900`、`1366×768`、`390×844` 真实浏览器截图。
- 正文对比度至少 `4.5:1`，控件与焦点至少 `3:1`；状态不只依赖颜色。
- 键盘可以完成导航、打开抽屉、选择日期、填写表单、取消和确认；焦点顺序与视觉顺序一致。
- 读屏可读页面标题、加载结果、错误、课程日期时间、候选来源和确认结果。
- Windows 11 Chrome/Edge 125%、150% 系统缩放与 200% 浏览器缩放可用；正式字体加载失败必须可检测。
- 当前 legacy 截图只作问题证据，不得作为正式页面视觉验收图。
