# T-010 当前教师网页审查

> 审查日期：2026-09-01
>
> 结论：当前页面只能作为 legacy 语义与问题证据，不能直接成为 V001 正式网页。
>
> 数据边界：本次只使用本机临时合成响应，没有连接现有数据库、真实账号、真实教师资料或外部服务。

## 审查范围

本次在当前代码上检查了 Agent、今日、学生、学生详情和日程。浏览器检查时配置为 `1440×900` 桌面与 `390×844` 手机视口；受页面滚动条与浏览器内容区影响，实际保存图片为：`01`–`03` 是 `1440×900`，`04`–`05` 是 `1425×891`，`06`–`09` 是 `375×812`。截图与哈希保存在 `evidence/t010-audit/` 并纳入本次审查证据；这些尺寸不计为正式页面三档验收通过。

## 流程步骤与健康度

### 1. Agent 桌面｜部分可用

证据：`01-agent-desktop-current.jpg`

- 优点：会话、消息、上下文和待确认操作已经区分；确认卡展示当前值与执行后结果。
- 问题：默认首页是 Agent，而 V001 的无外部依赖核心入口应为今日；技术动作名和英文对象类型暴露给普通教师。
- 风险：当前地址不随内部导航变化，刷新和深链不能可靠恢复会话或页面。

### 2. 今日桌面｜基本可读

证据：`02-today-desktop-current.jpg`

- 优点：课程、待确认和备忘分区清楚；服务端业务日期与生成时间可见。
- 问题：缺少统一的新增记录入口、离线/旧数据提示和刷新失败时保留旧内容的明确视觉层级。
- 风险：链接只改变内存中的页面状态，不能证明浏览器前进、后退、刷新和复制地址成立。

### 3. 学生列表桌面｜部分可用

证据：`03-students-desktop-current.jpg`

- 优点：搜索、新增、列表与档案摘要有基本分区。
- 问题：已有学生时右侧仍显示“请点击左侧”；学生行把链接嵌在按钮内，键盘与读屏语义不可靠。
- 风险：空列表、搜索无结果、加载失败和创建失败没有统一恢复动作。

### 4. 学生详情桌面｜不符合 V001

证据：`04-student-detail-desktop-current.jpg`

- 问题：页面承诺“自动识别并归档”，与 V001“识别结果先成为候选、教师逐次确认后才能进入正式记录”直接冲突。
- 问题：成绩、沟通、时间线和审核从上到下堆叠，长页面难以定位当前任务；来源、版本和确认状态不够突出。
- 要求：正式页必须改为“保存原始输入 → 生成候选 → 教师核对 → 确认入档”，不得复用当前归档文案或直写行为。

### 5. 日程桌面｜结构不符合已确认方向

证据：`05-schedules-desktop-current.jpg`

- 优点：周表能表达时间位置，课程状态有文字。
- 问题：周表仍是默认入口，和已确认的“月历概览＋选中日期议程”不一致；新增表单与列表在首屏下方，核心任务割裂。
- 风险：取消课程仍使用浏览器原生确认框，不能完整展示对象、变化、冲突和结果。

### 6. 日程手机｜勉强可读

证据：`06-schedules-mobile-current.jpg`

- 优点：周表在手机上退化成纵向日期列表，没有强制横向拖动课表。
- 问题：仍需连续阅读七天，不能快速从月历选择日期；顶部导航横向滚动且露出残缺入口。
- 风险：主要操作和页面导航竞争首屏空间，长列表会把新增课程入口推得很远。

### 7. Agent 手机｜不可用

证据：`07-agent-mobile-current.jpg`

- 问题：会话栏、聊天正文和上下文同时保留桌面宽度，正文与确认卡被横向截断。
- 问题：没有已确认的覆盖式会话抽屉，教师无法稳定阅读、切换或确认操作。
- 风险：截断的“当前/执行后”内容可能让教师在看不完整变化时确认高影响操作。

### 8. 今日手机｜内容可读、导航不合格

证据：`08-today-mobile-current.jpg`

- 优点：课程、待确认和备忘能按单列阅读，主要内容没有页面级横向溢出。
- 问题：顶部同时塞入主导航和辅助导航，需要横向滚动；当前入口、隐藏入口和退出动作无法一次理解。
- 要求：正式手机壳改为页面标题＋菜单抽屉，业务内容不再被横向导航挤压。

### 9. 学生手机｜主体可读、操作层级待重构

证据：`09-students-mobile-current.jpg`

- 优点：列表和新增按钮能在 390px 单列展示。
- 问题：列表条目、详情跳转和选择状态混在同一卡片；新增按钮压过当前学生信息。
- 要求：条目整体进入详情，新增作为页面主操作；筛选、空态与失败恢复保持同一位置。

## 最高优先级修正

1. 所有内部导航必须写入真实浏览器 URL，并支持刷新、深链、前进和后退。
2. 手机壳取消横向滚动的全量导航；Agent 改为覆盖式会话抽屉。
3. 日程默认改为月历概览＋选中日期议程，周视图仅作次级入口。
4. 删除“自动识别并归档”等绕过确认的文案与行为。
5. 所有高影响动作使用平台确认面板，展示对象、来源、旧值、新值、结果和失败恢复。

## 证据限制

- 截图只证明当前代码在合成数据下的可见状态，不证明正式功能、真实数据、Windows 11、键盘、读屏或生产环境通过。
- 未执行保存、取消、删除或确认等写操作；本次审查不产生业务数据。
- 当前截图不是正式视觉目标，只用于证明为何不能把 legacy 页面直接当作 V001 设计。
