## 已观察结果

- 桌面 1280×720：今日工作台、学生、周课表、缴费、反馈、设置和 AI 页面可浏览。课程行高度冲突已修复，无按钮文字挤压。
- 学生：打开新增弹窗、填写合成姓名/年级、保存后列表由 4 增至 5，出现“学生已添加”，焦点返回新增按钮。
- 排课：周历与状态入口可见，新增排期表单包含时间、地点、形式和参与人，取消后回到课表。
- 反馈：编辑正文并保存后显示“已保存”。
- AI：从欢迎页新建会话并发送合成消息，返回明确合成回复；确认卡片显示“演示确认”，执行后明确“未写入正式资料”。初始任务终态不再伪装持续输出；发送消息使用独立 ID 前缀，当前会话时间严格递增以避免同步重排。
- 手机 390×844：抽屉导航打开、选择页面后关闭并将焦点还给导航按钮；学生列表无横向溢出；新建会话/输入/发送可用。
- 手机 375×667 收起会话：实际 DOM 内宽 375、高 667，页面无横向溢出，发送按钮底边 633，仍在屏内。
- 手机 375×667 展开会话：列表限高且主区允许滚动；已实际输入并发送，滚动到底后发送按钮底边 632.78，未被裁切。键盘选择另一会话后自动收起列表已观察。
- 最后干净标签页：在默认主会话发送消息、演示确认、导航侧栏收放与切换工作台；控制台 error/warn 列表为空，见 browser-console-final.json。
- 登录：桌面双栏和手机单栏；服务不可达时保留明确错误/重试入口，未填入凭据或尝试真实登录。

## 发现并修复

独立静态审查指出手机裁切、账号菜单缺少方向键语义、演示保存冒充正式写入；分别修复并增加针对性回归。主 Agent 浏览器另发现 Card 默认内边距占用手机空间、图标归档按钮缺少名称、fixture 同时间消息同步重排；已修复。

工程全量门禁结果以 PROJECT_LOG 的 UI-003 条目为准。浏览器模拟尺寸不能代表真实手机键盘、安全区域和实际设备验收。
