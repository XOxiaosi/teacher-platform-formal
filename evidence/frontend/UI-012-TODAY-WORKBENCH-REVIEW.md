# UI-012｜今日工作台界面与流程样板

## 问题和边界

2026-09-29 用户确认“联盟工作台”指当前教师平台的“今日工作台”，同意把页面规划与用户流程做成可审阅的线框和状态样板。本文件只保存设计建议与审阅方式；产品语义仍以 PRODUCT.md 的 F02、F04、F06 和 UI-005 为准，样板不构成新需求认可。

本次要比较的是：教师打开首页后，哪一种信息顺序最容易让其发现当日课程、待核对材料和下一步操作。沿用 UI-003/004 已认可的浅色、青绿色和现有教师导航。AI 助手保持独立入口，不在首页恢复助手内部看板。

## 三种可切换布局

| 布局 | 页面骨架 | 适合判断的问题 |
|---|---|---|
| A 日程优先 | 今日概览 → 左侧课程、右侧学生情况与备忘；取消课程折叠 | 教师能否先看清当天教学节奏，再处理材料 |
| B 任务优先 | 大面积“下一步行动” → 右侧精简课程表 | 教师能否更快找到需要立即进入的任务 |
| C 时间轴 | 按时间排列课程 → 侧边学生情况 | 时间先后与课间待办能否一起理解 |

页头提供“安排课程”和“问教学助手”的入口位置。课程摘要只用时间、对象、地点、状态；待核对材料展示学生归属、来源、接收时间、原话及记录状态，拟记录内容在详情中查看。教师点击课程或材料后可审阅详情位置；样板按钮只返回本页演示回执。

## 用户流程与状态

1. 登录后进入今日工作台，读取北京时间日期、课程数及待核对数。
2. 课程路径：看课程状态 → 打开详情 → 在正式业务页核对出勤、课时和记录 → 查看实际回执。样板只展示详情与处理入口，B02 未决定的扣课数量不在样板中推定。
3. 材料路径：看学生或待确认归属、原话及来源 → 打开拟记录内容 → 核对或补充 → 正式保存后查看记录。收到材料、教学记录保存和微信回复状态分别表达。
4. 空状态：课程和材料分别给出真实空文案；课程区保留排课入口。
5. 失败状态：保留原话与拟记录内容，展示失败及重试入口，不显示为已保存。

样板情境为 `normal`（待上、已完成、已取消课程；待核对与已记录材料）、`review`（多条待核对，含归属不明）、`empty` 和 `failure`。所有姓名、课程和原话均为合成资料，状态只在页面内存中演示，刷新后重置。

## 审阅入口

在仓库根目录执行 `npm.cmd run legacy:frontend`，打开：

`http://127.0.0.1:5173/design-review.html?prototype=today&variant=A&state=normal#/today`

底部切换栏的箭头切换 A/B/C；下拉框切换四种情境。键盘左右方向键也可切换布局，聚焦输入或选择控件、打开详情弹窗时不会切换。链接中的 `variant` 与 `state` 可以分享并在刷新后恢复选择。样板仅在 Vite 开发环境启用，正式构建不显示该入口或切换栏。

## 审阅结论待补

- 待用户选择布局或指出要组合的区块、视觉和文案修改意见。
- 用户审阅与工程检查分开记录；当前不将任何一个样板视为已认可的正式工作台。
