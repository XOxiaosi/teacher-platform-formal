# V005 测试版反馈与功能缺口核验

日期：2026-09-08。证据定位：本轮只核对可操作原型与保留接口，不替代 PRODUCT / PROJECT_LOG 的产品和任务事实；后续进度只读 PROJECT_LOG。

## 用户五项反馈的验收关系

| 反馈 | 可见验收 | 不应发生的变化 |
|---|---|---|
| 学生资料修改（王浩然） | 列表/详情可改姓名与年级；相关页面按同一学生编号同步显示 | 不改余额、编号与历史记录；取消不写入 |
| 课程修改 | 今日、课程、学生详情入口可打开编辑；展示变化后确认 | 完成课程不改时间、参与人或扣课流水 |
| 课程分列 | 时间、地点、对象、备注、操作可区分；小班摘要只显示人数，详情展开名单 | 不重新引入课程内容、科目或目标 |
| 一次或每周重复 | 星期、起止、暂停；本次/本次及以后明确区分；切到远期仍能看到 | 不提前扣课、不覆盖完课、不复生已取消例外、不静默跳过冲突 |
| 模型与微信页面 | 本地选择/保存/取消、配置导航、检查未接入与连接步骤说明 | 不存密钥、不联网、不伪造连接成功或二维码 |
