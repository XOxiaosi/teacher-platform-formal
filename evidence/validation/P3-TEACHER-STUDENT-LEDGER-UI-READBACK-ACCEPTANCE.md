# P3-TEACHER-STUDENT-LEDGER-UI-READBACK-03｜教师学生详情权威余额与课时流水只读投影验收

日期：2026-09-21（America/Los_Angeles）

## 验收目标

教师从正式工作台打开学生详情时，页面必须读取权威课时余额与不可变流水，展示已购、已消耗、调整和当前剩余四项数据。加载、空结果、失败重试和切换学生都必须有明确状态；正式读取失败时不得回退到预览假数据，也不得把前一个学生的迟到响应展示给当前学生。

本包只接入正式只读接口。它不修改数据库 schema、迁移、缴费、赠课、退款、人工调整、完课扣课或 B02 尚未决定的计费数量规则，也不调用真实 DeepSeek、微信、发送或部署路径。

## 实现范围

- 正式学生详情挂载独立的 `StudentLedgerReadback`，并行读取 `/students/:id/balance` 和 `/lesson-ledger/entries?studentId=...`。
- 余额固定展示 `purchased`、`attended`、`adjustments`、`remaining`；流水展示业务类型、课时正负数、北京时间和服务端原因。
- 加载时清空旧数据；失败时只显示错误与重试；教师、学生或刷新令牌变化时重新读取，并丢弃已过期请求的迟到响应。
- 正式工作台提供权威流水后，隐藏预览数据中的“完成课时记录”假流水；纯预览页面保持原行为。
- 前端 API DTO 与后端账本条目字段对齐。后端只纳入既有 `GET /lesson-ledger/entries` 路由，不纳入同文件中未提交的缴费幂等、调整准备或调整确认写路径。
- 流水服务在指定 `studentId` 时先按当前 session 教师验证学生归属；不存在或跨教师引用统一返回 `404 NOT_FOUND`，未指定学生时仍返回当前教师范围集合。

## 验收场景

- 正式学生详情显示四项余额、赠课等流水类型、正负课时、原因和北京时间。
- 空流水显示明确空状态；任一请求失败时不展示余额或演示流水，教师可重试。
- 切换学生时，即使原学生请求更晚返回，也不会覆盖新学生内容。
- 从账号菜单刷新资料后重新读取余额与流水。
- 正式学生详情不再显示预览完成记录；预览模式未注入权威面板时仍保留既有内容。
- 认证 HTTP 流水读取保持 session 教师范围、跨教师隔离、跨服务上下文一致，并且重复 GET 前后业务表计数不变。

## 完成边界

本证据覆盖合成数据下的正式教师端只读展示与认证 HTTP 读取，不证明真实教师资料、真实模型、微信、真实设备/Windows、发送或部署通过。非法流水日期参数校验和 P3 写事务属于后续独立工作包；B02 继续阻塞正式计费数量写入。
