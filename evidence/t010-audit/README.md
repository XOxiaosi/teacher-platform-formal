# T-010 当前网页截图证据

这些截图由当前本地教师网页在 2026-09-01 使用合成响应生成，用于证明 legacy 页面的问题边界，不是正式视觉设计或产品完成证据。

- 浏览器配置：桌面 `1440×900`、手机 `390×844`。
- 实际保存像素：`01`–`03` 为 `1440×900`，`04`–`05` 为 `1425×891`，`06`–`09` 为 `375×812`；差异来自页面滚动条与浏览器内容区。
- 这些图片只证明当前 legacy 问题，不计为合同要求的正式页面三档截图 Gate 通过。
- 只执行登录态读取与内部页面切换，没有执行保存、确认、取消、删除或其他写操作。
- 没有连接真实数据库、账号、资料、外部供应商或密钥。
- 页面数据中的教师、学生、课程、会话和金额均为虚构合成内容；截图与哈希作为本次可复核证据纳入仓库。
